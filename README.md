# SYN-COCO (COCO vs Synthetic)

This repo contains our **Graduation Project 1** work on building a COCO-like object detection dataset where images are generated with **Nano Banana (Gemini 3)**, then annotated and exported in YOLO format.

Core idea:
- Follow the **same 80 MS-COCO classes**
- Generate diverse prompts for each class (LLM-driven prompt diversification)
- Generate images with Nano Banana (Gemini 3)
- Annotate with Roboflow
- Train YOLO models later (GP1 focuses on methodology + dataset setup, not final training results yet)

## Repository structure

### `COCO VS SYN/COCO vs Synthetic.v1i.yolov11/`
Annotated dataset exported from **Roboflow** in **YOLO format** (images + labels + split structure).

### `COCO VS SYN/`
Quick visual comparison samples:
- Some original images from **MS-COCO**
- Some images generated by **Nano Banana (Gemini 3)**

### `SYN_COCO Overleaf/`
Our Overleaf project folder:
- `main.tex`
- `references.bib`
- `figs/` (paper figures)

### `SYN_COCO.pdf`
The current proposed paper / report for Graduation Project 1 (methodology, pipeline, and plan).

### `coco.yaml`
The original COCO YAML listing the **80 classes** we follow when generating SYN-COCO.
